# Prompt Summary

All raw images were generated with the `generate2dsprite` workflow using built-in image generation.

Global constraints:

- Clean HD realistic 3D game asset sprite sheet.
- Solid `#FF00FF` background for sprite processing.
- No text, labels, borders, or guide marks.
- Consistent 3/4 front camera angle and scale within each version.
- The same stone identity should persist through all stages.

## 当前玩法

- 流程顺序：`切除 -> 修补 -> 定型 -> 清洁`。
- 成石没有切除/定型。
- 原石一定有切除，大部分有定型。
- 所有素体都以清洁收尾。
- 左侧素体列表支持拖拽和点击直接进入玩法。
- 右上角为 GM 测试区：直接完成、退出玩法、窗口比例、流程数据包、重置演示数据。
- 镜片通过滚轮上下翻转；正确镜片出现瑕疵高亮并锁 0.3 秒。
- 完成清洁后宝石放大、发光、飞出收集。
- 右键可领取奖励；无奖励时不显示右键提示。

## 当前 UI 与布局

- 视觉方向为金绿工坊 UI。
- 层级关系：操作提示 UI 层 -> 信息层 -> 瑕疵层 -> 镜片层 -> 石头层 -> 底盘表演层 -> 背景长方形层。
- 圆形镜片回归，镜片上下超出画面，营造第一人称镜片感。
- 镜片翻转为上下翻转，不是左右翻转。
- 主玩法中心已加锚点：镜片、宝石、座垫、瑕疵围绕玩法窗口中心。
- 小高度屏幕通过 `--gem-size`、`--lens-view-scale`、`--lens-flip-mid-scale` 缩放主玩法内容。
- 手机横屏布局已存在：左侧约 6 个素体可见，工具右上，镜片左下，奖励盘贴右下/最右，收集按钮在右侧，压缩笔记本显示在玩法左上。

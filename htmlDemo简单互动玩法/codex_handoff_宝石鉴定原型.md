## 磨平玩法当前状态

内部类型仍是 `chamfer`，显示名已改为 `磨平`。

核心规则：

- 必须切到该宝石清洁步骤对应镜片，才能看到轨道和尖角并操作。
- 错误镜片下仍可看到砂布在外侧浮起，但不能操作完成。
- 轨道贴合宝石外圈，砂布不能脱离轨道跟随鼠标，也不能从宝石中心穿过去。
- 当前每颗磨平宝石是 3 个不等距尖角。
- 每个尖角需要来回有效通过 3 次。
- 尖角处阻滞感已加强：砂布抖动、尖角高亮、轨道反馈都会更明显。
- 每个尖角完成后，宝石中心会发一次柔光，暗示该角已经完成。
- 完成每个尖角后，会提前显示一部分下一步清洁的灰尘预览。
- 最后一个尖角完成后不会立刻瞬切，留一点收尾演出：砂布先跟随玩家最后拖拽方向，再淡出并进入清洁。

砂布资源：

- 当前运行素材：`assets/ui_v26/ui_tool_sprites/tool_chamfer_cloth_A.png`
- 仍保留 CSS 占位砂布作为图片加载失败兜底。
- 桌面显示尺寸约 `96x64px`；手机横屏约 `76x50px`。

## 工具入镜状态

- `寻光`：
  - 工具全程跟随鼠标/触点。
  - 闲置时只显示手电筒，不开光源。
  - 左键/按住操作时才打开光束。
  - 越靠近隐藏反光点，折射线、局部亮线和星芒越明显，但保持克制。
- `切除`：
  - 浮空等待刀固定在宝石右上方，位置更高且离素体更远。
  - 等待时刀屁股稳定，刀头朝鼠标方向。
  - 每一刀成功时，同一个刀工具从悬挂点移动到光效起点，刀片对齐切线移动到终点，再回到悬挂点。
  - 旧飞行刀特效保留代码但当前隐藏，用于对比。
- `修补`：
  - 滴液工具默认悬浮左上等待点击。
  - 第一次滴液后停在当前裂缝目标上方；下一次滴液再移动到下一个目标。
  - 不再每次点击重建工具 DOM，避免闪烁。
- `定型`：
  - 工具跟随鼠标/触点。
  - 闲置跟随时只保留小火焰；按住描画时恢复完整喷射。
- `清洁`：
  - 小刷子跟随鼠标，刷头前端中心对齐鼠标位置。
  - 闲置不晃动；左键按住擦拭时恢复刷头晃动。
- `磨平`：
  - 不跟随鼠标，只沿轨道运动。

## 清洁与完成演出

- 清洁完成时不会立刻切走，会先动态移除剩余污渍。
- 清洁最后的完成演出已成为所有宝石完成时的通用收束，不会定型后直接进入小盘掉石头。
- 宝石整体完成后进入出石阶段：
  - 镜片区域临时缩小并偏左下。
  - 成石盘放大并移动到更中心。
  - 小宝石从上方中间掉入盘子，中间落点附近再随机移动。
  - 宝石之间有轻量物理碰撞、反弹和互相推开。
  - 掉落后记录最终点位，移动布局或重渲染不从头播放。
  - 右上刷新键现在是“从头落下一次所有宝石”，不保留当前落点。
  - 出石阶段单击画面可以快速结束演出。
  - 出石阶段单击下一个素体，会快速结束演出并直接开始下一颗修复；已完成宝石不会撤回重修。
  - 宝石停止移动后约 1 秒，盘子和镜片恢复原样。

## 手柄模拟状态

键盘模拟：

- `WSAD`：左摇杆
- `F/V/C/B`：十字键
- 方向键：右摇杆，用于玩法内瞄准
- `Q/E`：L1/L2，切换镜片
- `U`：R1
- `O`：R2
- `K`：A
- `L`：B
- `I`：Y
- `J`：X
- `H`：Start，等于点击开始游戏/开始修复
- `G`：Option，触发退出当前模式确认接口

交互规则：

- 所有模式都不提供切工具入口，工具跟随当前步骤自动切换。
- 素材选择阶段：`WSAD` 和 `F/V/C/B` 都能选择素体。
- 素材选择阶段：`L1/R1` 用作排序选择按钮。
- `R2(O)` 按住才显示瞄准靶，瞄准靶每次从画面中心出现，松开消失。
- `R1(U)` 和 `A(K)` 在玩法里等价，都是确认/落刀/落刷。
- 未按住 `R2` 时，`R1/A` 不执行工具，只提示先开镜。
- `Y(I)` 收集奖励。
- `X(J)` 在素材选择和玩法之间切换。
- `B(L)` 打开退出确认；确认用 `A/R1`，取消用 `B/Esc`。
- 手柄说明图已从顶部移除，应显示在手柄模式的说明区域/玩法旁，不要挤压玩法窗口。

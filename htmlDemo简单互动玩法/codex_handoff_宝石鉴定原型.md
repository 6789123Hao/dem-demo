## 1. 项目定位
这是一个**单文件 HTML / CSS / JavaScript 的一页式玩法原型**。

目标不是做完整大世界，而是做：
- Hub 主页面
- 点击交互节点后弹出的模式选择
- 进入对应小游戏页面
- 完成 Lens / Face / Tool 的识别与处理流程
- 定形 / 收光阶段
- 奖励结算页

当前原型用于验证：
- UI 布局
- 输入方式
- 宝石处理流程
- 不同地区 / 不同宝石的流程配置方式

## 3. 当前核心玩法

### 3.1 观察维度
玩家需要同时匹配：
- 正确 Lens
- 正确 Face
- 正确 Tool

只有三者都正确时，才能成功处理当前目标。

### 3.2 Lens
当前有 3 个镜片：
- Lens A
- Lens B
- Lens C

用途：
- 某些缺陷 / 切除点只在指定 Lens 下可见

切换方式：
- 点击 `Lens Switch`
- 鼠标滚轮向下
- 上到下拖拽
- TP 模式点击角色也会切 Lens

表现：
- 旧镜片向下移出
- 新镜片从上方放入

### 3.3 Face
当前有 3 个观察面：
- Face 1
- Face 2
- Face 3

切换方式：
- 点击 Rotate Left / Rotate Right
- 左右拖拽

当前约定：
- 左→右拖拽 = 逆时针 = `rotateFace(-1)`
- 右→左拖拽 = 顺时针 = `rotateFace(1)`

### 3.4 Tool
当前工具分两类。

#### 常规工具
- 清洁
- 修补
- 切除

#### 特殊阶段工具
- 定形
- 收光

工具规则：
- 当前步骤是什么，就只能用对应工具
- 工具错误时不允许消除目标
- 观察条件错误时不允许消除目标

## 4. 当前输入方式

### 4.1 鼠标
- 点击按钮
- 点击缺陷
- 拖拽切 Face / 切 Lens
- 滚轮向下切 Lens

### 4.2 键盘
当前仅支持：
- `Q`：常规工具向上切换
- `E`：常规工具向下切换

Q/E 只在这三个工具中循环：
- 清洁
- 修补
- 切除

**不包括：**
- 定形
- 收光

### 4.3 拖拽误触保护
- 缺陷按钮有 pointer drag guard
- 防止拖拽切 Face / Lens 时误点缺陷

## 5. 当前阶段流程

### 5.1 常规处理阶段
玩家通过：
- 观察 Lens
- 观察 Face
- 切换工具
- 点击缺陷

完成当前瑕疵处理。

### 5.2 洁净判定
当当前宝石不再存在：
- 缺陷
- 杂质
- 切除点

会触发：
- 洁净闪光
- 短暂锁交互
- 然后自动进入下一阶段

下一阶段可能是：
- 定形
- 或直接收光

### 5.3 定形阶段
仅原石进入定形。

规则：
- 不是玩家自由选形状
- 每颗原石绑定固定目标形状
- 通过叠加大轮廓引导玩家处理
- 当前实现为：点击轮廓即可完成

镜头表现：
- 定形时宝石放大到 **140%**

定形完成后：
- 宝石形状发生变化

### 5.4 收光阶段
规则：
- 进入收光后，选中收光工具
- 点击宝石即可完成收光

镜头表现：
- 收光准备阶段，宝石放大到 **220%**

完成表现：
- 白色薄膜
- 闪光
- 进入结果页

## 6. 视觉与交互表现

### 6.1 整体 UI 风格
当前整体风格是：
- 暖色系
- 木色系
- 木制鉴定箱内部的感觉
- 像打开后的工作盒 / 鉴定盒

### 6.2 2D 宝石表现
2D 宝石不是只靠文字切换面。

当前实现：
- 用上下滚动的纹理条表示 3 个 Face 相连
- Face 切换时，纹理条上下平移

### 6.3 3D 宝石表现
3D 宝石是简化的几何切面体。

当前实现：
- 通过旋转角度表现不同 Face
- 可结合材质颜色与轮廓切换

### 6.4 原石表现
原石当前有：
- 深色外皮 / 杂层
- 外皮会跟随当前 Face 旋转
- 切除后外皮表现会消失
- 定形完成后轮廓变化

### 6.5 缺陷反馈
点击正确缺陷时：
- 宝石抖动
- 粒子效果
- 使用当前宝石本体，不使用默认替代图

### 6.6 完成反馈
- 洁净时：闪光 + 暂停交互
- 收光完成时：白膜 + 闪光
- 最后结算

## 7. 当前 UI 布局

### 7.1 FP 模式
布局重点：
- 右上角：Lens Switch
- 宝石右侧：Special Tool（定形 / 收光）
- 宝石下方横排：常规工具（清洁 / 修补 / 切除）
- 宝石右边：滚轮向下图标提示
- 左下角和右下角：双手臂表现

双手逻辑：
- 左手偏向旋转操作
- 右手偏向切 Lens / 持工具

### 7.2 TP 模式
布局重点：
- Observe Area 在左侧
- 左上角：Lens 状态
- 左下角：Case Info
- 右侧竖条：Special Tool（定形 / 收光）
- 宝石下方横排：常规工具（清洁 / 修补 / 切除）
- 右侧角色区单独展示角色

角色逻辑：
- 点击角色切 Lens
- 切 Lens 时角色换姿势
- 角色右手持工具会随当前工具变化

### 7.3 当前操作提示
当前已经加的提示：
- 清洁左边带 `Q`
- 切除右边带 `E`
- 宝石右边带“滚轮向下”提示图标

  - 透光：玩家拖动手电筒，光线始终朝向宝石；只有正确角度会在对面透出光，松手完成。
  - 硬度：宝石放大；划片从左往右慢速稳定滑过，速度太快/太慢/偏移都会失败，失败后划片复位。
  - 称重：使用 3 个样品/目标石做从轻到重排序；目标石可能是轻/中/重，按宝石类型变化。
- 证据卡演出：
  - 每完成一步都会生成一张左下角证据卡。
  - 证据卡覆盖叠放，轻微左右旋转并露出后面的纸边。
  - 最后检验完成时所有证据一起归档，档案更新。
- Lens 反馈：
  - 当前 Lens 不对时，道具变暗并禁用。
  - 同时出现“鼠标下滚轮切 Lens”提示。
- 批量管道：
  - 三段翻转结构：`A/B -> C/D -> E/F`。
  - 按钮名为“运行已知批量”。
  - 只处理已识别且当前管道配置匹配的宝石，未知或流程不匹配的留在桌面。

- 奖励日志默认只显示最近两行，点击展开，点击外部收回。

### 任务顺序规则

- 原石：一定从 `切除` 开始，可能包含 `修补`，大部分包含 `定型`，最后一定 `清洁`。
- 成石：不走 `切除` 和 `定型`，可以走 `修补`，最后一定 `清洁`。
- 珍珠当前也加入 `修补 -> 清洁`，避免三星成石过快完成。
- 所有步骤都应该复用前一步的石头状态，让切除、修补、定型、清洁对宝石外形有连续影响。

### 当前交互表现

- 清洁热点文案显示为 `←擦→`。
- 切除热点文案显示为 `滑→→→`，提示玩家沿长条方向拖拽。
- 定型热点加入 `描边` 提示。
- 黑曜石等三角定型不应再出现三角背后的方形框；三角目标只显示三角形和描边提示。
- 切除和定型完成时有下落碎片反馈。
- 修补每次点击后裂痕逐步减弱。
- 清洁完成时触发闪光并收入奖励。

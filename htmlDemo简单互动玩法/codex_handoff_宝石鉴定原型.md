## 当前玩法状态

- 基础流程仍围绕 `切除 -> 修补 -> 定型 -> 清洁`。
- 成品石没有切除/定型，会随机在修补前插入 `寻光`，目标顺序为 `寻光 -> 修补 -> 清洁`。
- 原石保持切除开场，大部分有定型，部分有修补，最终以清洁收尾。
- `寻光` 已接入工具轮、镜片提示、笔记本、GM 一键完成和拖拽流程；鼠标/触控点击点是探测圆心，手电筒和射线从右上方照入圆圈。越靠近隐藏反光点，光束细折射线、局部星芒和宝石表面亮线越明显，但强度保持克制。
- `修补` 是裂缝瞄准和精华填充：三段裂缝目标、精华滴液下落、裂缝填充到 80% 后变细消隐。裂缝和滴液在镜头下层，不再用大水滴遮挡宝石。
- `清洁` 使用 `.gem-surface` 污渍材质层和 `clean-erase-mask`；横向擦拭提示、灰尘、颗粒和污渍在同一层内，玩家擦过的位置会一起被擦掉。
- `定型` 成功后会复制玩家笔画，生成青蓝激光形状，从镜头前方向宝石中心收缩投射。
- `切除` 成功后会播放刀片划过和白色切线特效。
- `浸润` 当前不开放：`玛瑙`、`萤石`、`萤石测试` 的流程入口已移除，工具轮也不再出现 `soak`。旧量杯代码暂时保留为不可达实现，方便以后恢复或重做。
- `磨平` 已作为实验玩法接入 `珍珠`、`玛瑙` 清洁前一步：必须切到各自清洁镜片，显示贴合宝石外缘的轨道和 3 个不等距尖角；玩家拖拽小砂布沿轨道来回通过尖角，每个尖角 3 次有效往返后完成，并提前显出局部清洁污渍预览。当前已经把显示名从 `边缘倒角` 改为 `磨平`，内部类型仍沿用 `chamfer`。灰尘预显不再是块状横条，改为更大一点的软边灰尘团；拖拽中 overlay 不再每帧重建，避免灰尘闪烁。尖角阻滞已增强：卡住时砂布抖动更明显，当前尖角金色脉冲，轨道线变亮。当前候选砂布图已复制到 `tool_chamfer_cloth_A.png`，显示尺寸已放大且方向已翻转为尖角朝外、布面朝内；砂布旋转已做连续角度处理，避免左侧跨角度边界时突然自旋；轨道半径已外扩，更贴近宝石表面。最新调整：总进度条改到宝石下方直线显示，并再次下移、变薄，尽量贴近镜片底部不压住宝石；错误镜片下仍能看到外侧浮起的砂布，正确镜片下平滑靠近；正确镜片且尚未拖动时会慢慢浮出左右拖拽箭头，拖拽后隐藏。磨平文案统一为“沿宝石边缘来回摩擦直到光滑为止”。砂布已移除 `left/top` 直线补间，只按轨道角度步进后的点渲染，避免脱离轨道跟随鼠标或从宝石中心穿过。最后一个尖角完成后会延长收尾演出，先跟随玩家最后拖拽方向，再光滑淡出并进入下一步。CSS 占位砂布保留为加载失败兜底。
- `萤石测试 fluorite_test` 是新增 GM/测试用石，复用 `assets/gems_v24/fluorite` 图片素材，默认在全量流程包里 1 颗。固定流程：`切除 -> 寻光 -> 修补 -> 定型 -> 磨平 -> 清洁`，用于一颗石头内验收当前开放的主线玩法逻辑。

## UI 与交互要点

- 视觉方向：金绿工坊 UI，奖励盘、镜片、笔记本和工具入镜都围绕这个语言做；右侧工具箱窗口当前已隐藏。
- 工具入镜规则：`寻光`、`定型`、`清洁刷` 在正确镜片下全程跟随鼠标/触点，使用右上偏移；`寻光` 闲置时只显示手电筒，按住左键才开光束/光斑；`定型` 闲置跟随时只保留小激光，按住描边时恢复完整喷射；`清洁刷` 闲置不晃，按住擦拭时刷头恢复左右扫动。`切除` 的刀固定悬浮在宝石右上方且位置更高，刀口朝向鼠标，成功滑切时刀从悬浮位移动到滑动起点，跟白线到终点，再回到悬浮位；旧飞行刀代码保留但当前隐藏用于后续对比。`修补` 的滴液笔在正确镜片等待点击时悬浮在左上角，第一次滴液后停在当前目标上方，下一次再移动到下个目标。`磨平` 不跟随鼠标，只沿轨道运动；左右拖拽提示贴在砂布身体两侧并随砂布角度旋转。
- 玩法中心锚点不要漂：镜片中心、宝石、座垫、瑕疵/工具反馈都围绕 `.lens-stage` 中心稳定布局。
- 鼠标滚轮上下翻镜片；正确镜片下显示当前步骤热点/提示，错误镜片只提示切换。
- 桌面镜片显示默认是 `三文字式`；GM 下拉可切 `三角式`、`三文字式`、`轮盘式`、`一字式`。
- 桌面轮盘式镜片：固定金色选择圈，镜片围绕轮盘中心转动；镜片本体不再额外 active 描边。
- 左侧素体列表在桌面支持点击和拖拽进入玩法；手机横屏不支持拖单颗素体入镜片，但支持点击选择素体，并可纵向拖动整列查找。当前修正点：手机横屏素体列表只有确认纵向拖动超过阈值后才捕获指针，避免轻触点击被误判成拖拽。
- GM 区只用于测试，正式玩法区不放一键鉴定；GM 按钮文案是 `GM一键完成当前`。
- 教程弹窗 6 页，首次进入会自动弹出；每页有图片占位区，后续可替换真实图。
- 标题区已接入半透明布袋水印，使用 `bag_open_down_F_ivory_oblique_v1.png`；当前已提高透明度并取消 `soft-light`，桌面应明显可见但仍在标题文字后方。手机横屏隐藏该装饰。旧的 `bag_open_down_A.png` 和候选夹中 A-D 四张非 explicit 布袋图已删除，因为用户判定它们畸形。

## 手柄模拟状态

- GM 布局下拉可切 `手柄模拟`。
- `WSAD` 模拟左摇杆，`F/V/C/B` 模拟十字键；两组都能在素材选择焦点下移动素体高亮。
- 方向键只模拟右摇杆，用于玩法内瞄准；不要再拿方向键选素材。
- `Q/E` 是 `L1/L2`，玩法焦点下切镜片；素材选择焦点下 `Q(L1)` 按数量排序，`U(R1)` 按星级排序/反转。
- `O=R2`：按住才开镜和显示瞄准靶；每次开镜从中心出现，松开隐藏。
- `U=R1` 与 `K=A`：玩法焦点下确认/落刀/落刷；未开镜时只提示先按住 R2。
- `I=Y`：收集奖励；未打开弹窗时打开奖励弹窗，弹窗打开时领取。
- `J=X`：处理中在 `素材选择/玩法` 焦点之间往返；切到素材选择会收起瞄准并停止当前工具。
- `L=B`：玩法中打开退出确认弹窗，避免误触退出；确认用 `A/R1`，取消用 `B/Esc`。
- 手柄模拟布局顶部不再显示手柄预览；右侧 `.gamepad-guide` 面板显示完整 `gamepad_keymap_A.png`，旧文字键位格子在手柄模式隐藏，当前焦点/操作状态文字仍保留。当前 `gamepad_keymap_A.png` 是 720x480 新版：按用户参考图把 Q/E、WSAD、F/C/V/B、G/H、U/O、I/J/L/K 和右摇杆十字准星直接排布在手柄对应区域，字色改为象牙金+深绿描边，避免红字看不清。
